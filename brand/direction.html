Round 2 routes, for reference

Kept below so you can compare: round 2 palettes, type pairings and each route in use. All wordmarks are in the gallery above.

Colour

All three palettes move the background off beige to a cool mineral grey and set text in graphite. The accent comes from the mood board's livery red and appears only on the primary button, live data points and small highlights. Contrast ratios are measured live against the page background (WCAG AA: 4.5:1 for body text, 3:1 for large text and graphics).

A Rosso

Truer racing red.

B Ember

Orange-red, slightly bluer grey.

C Rosso + Ember

Your mix. Recommended.

The current background #f4f2ee and grey #9b978f (2.6:1, fails AA) are both retired. In every palette the bright accent is never used for small text: it has a darker text shade, and the button fill is tuned so white button text passes AA.

Type

Each route now brings its own pairing: one grotesk for every word, plus that font's tabular numerals for scores and metrics only. The expanded width stays in the wordmark. Both fonts are self-hosted, so there are no third-party font requests.
